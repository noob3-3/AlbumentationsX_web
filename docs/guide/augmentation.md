# 数据增强

![数据增强](/screenshots/07-augmentation.png)

增强会基于源数据集生成新图片，用于扩充训练样本。此功能需要 [软件授权](/guide/license)。

## 操作

1. 选择 **当前项目** 与 **源数据集**。
2. 设置 **增强倍数**（每张原图生成多少张增强图）。
3. 选择 **预设配置** 或 **自定义**。预设一般包含轻度 / 中度 / 强度 / 分类等方案，可展开查看包含的变换。
4. 点击 **创建增强任务**。右侧 **增强任务列表** 可查看进度与状态，必要时刷新。

训练时只会使用 **已标注** 的图片（含已标注的增强图）。增强完成后请到 [数据标注](/guide/annotation) 检查或补标。
