# 软件授权

平台使用离线机器码激活。未激活时，训练、数据增强、模型验证、模型部署、自动标注和 ONNX 导出不可用。

浏览项目、采集图片、手工标注等不依赖授权的功能仍可使用。页面顶部会出现红色提示条，右上角授权标签也可点击进入激活窗口。

## 激活步骤

1. 打开平台后，点击右上角授权状态标签（例如「未激活」）。
2. 在 **软件授权** 对话框中复制 **机器码**。
3. 将机器码发给厂商，获取激活码。
4. 把激活码粘贴到对话框，点击 **激活**。
5. 成功后状态会变为已授权（含到期日或永久）。刷新页面即可使用被拦截的功能。

对话框下方会显示本机主机名、网卡、硬盘等信息，便于核对是否为当前机器。

## 说明

- 激活码与当前机器绑定。换机、大幅变更网卡 / 硬盘后可能需要重新签发。
- 授权文件写在软件数据目录的 `license.dat` 中，不要把它提交到公开仓库。
- 到期后相关功能会再次被拦截，请联系厂商续期。
