# 模型训练

![模型训练](/screenshots/03-training.png)

使用 Ultralytics YOLO 训练目标检测模型。需要先 [激活授权](/guide/license)，并在顶部选择 **当前项目**。

## 创建任务

1. 填写或确认 **任务名称**（选择数据集与基础模型后可自动生成，也可手改）。
2. 选择 **数据集**、**基础模型**（如 YOLOv8 / YOLO11 各尺寸 `.pt`）。
3. 按需勾选 **继续训练**、**类别增强** 等。
4. 在 **训练参数** 中设置轮数、批大小、输入尺寸、学习率、验证集划分比例、**设备**（CPU / 指定 GPU / 多卡）。
5. 展开学习率与正则化、数据增强参数、损失权重、高级参数可做细调。
6. 点击 **开始训练**。下方任务列表显示状态（进行中、完成、失败、已取消），可进入 **训练详情** 查看曲线与日志。

## 数据集提示

- 训练只使用 **已标注** 图片。
- 若数据集含增强图且部分未标注，页面会提示数量，并可跳转去标注。
- 下拉框无数据或禁用时，先确认已选择当前项目，且该项目下已有数据集。
