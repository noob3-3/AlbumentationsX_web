# 常见问题

| 现象 | 建议 |
|------|------|
| 下拉框无数据或禁用 | 先在顶部选择 **当前项目** |
| 训练 / 增强 / 部署 / 验证 / 自动标注不可用 | 查看右上角授权状态，按 [软件授权](/guide/license) 激活 |
| 训练找不到数据集 | 确认数据集属于当前项目，且已有标注 |
| 远程推送失败 | 检查 Token、网络、目标数据集 ID 与接口路径 |
| GPU 不显示或不可用 | 查看概览页 GPU 信息；训练页设备选择需与服务器 CUDA 环境一致 |
| 桌面版打不开页面 | 确认 `启动.bat` 与 `AlbumentationsX.exe` 在同一目录；浏览器访问 `http://127.0.0.1:8000/` |

界面文案或部署地址若有变更，以实际环境为准。
