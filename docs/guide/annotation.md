# 数据标注

![数据标注](/screenshots/05-annotation.png)

1. 选择 **当前项目**，再选择 **数据集**。
2. 进入标注画布后，用工具栏框选、改类名。
3. 可使用 **自动标注**、**批量替换类别**、**删除类别** 等（未选数据集时部分按钮不可用）。自动标注需要 [授权](/guide/license)。
4. 可按需切换仅原始数据、显示增强数据；**批量标注管理** 用于批量流程。
5. 开启 **携带标注** 后，切到「无标注」的图片时会带上当前画布的框；若下一张已有标注，则显示该图自己的标注。

## 快捷键

| 按键 | 作用 |
|------|------|
| `A` | 上一张 |
| `D` | 下一张 |
| `Alt + ← / →` | 快速翻页 |
| `W` | 绘制 / 选择 |
| `Ctrl + S` | 保存并跳到下一张 |
| `Ctrl + P` | 保存并跳到上一张 |
| `Ctrl + Enter` | 仅保存，不跳转 |

输入框聚焦或下拉展开时，快捷键不会触发。
