# 开始使用

本文档说明 **VST 目标检测训练平台** 的日常操作。界面以左侧导航 + 顶部「当前项目」为核心，多数功能需先选择项目后，列表才会按项目过滤。

## 推荐流程

1. [激活软件](/guide/license)（训练、增强、自动标注、部署、验证、ONNX 导出需要授权）
2. [创建并选择项目](/guide/projects)
3. [采集图片](/guide/collect) 到数据集
4. [标注](/guide/annotation)（可选 [数据增强](/guide/augmentation)）
5. [训练模型](/guide/training)
6. 在 [模型管理](/guide/models) 中查看权重，再 [部署推理](/guide/deployment) 或 [对比验证](/guide/validation)

## 如何打开平台

### 桌面版（Windows）

1. 把 `启动.bat` 放在 `AlbumentationsX.exe` 同一目录，双击启动。
2. 程序会在本机拉起服务，并打开浏览器，默认地址：`http://127.0.0.1:8000/`。
3. 根路径 `/` 会自动跳转到 **概览**（`/dashboard`）。

### 浏览器访问（已部署的服务）

1. 在地址栏输入平台地址（内网示例：`http://<主机>:8000/dashboard`）。
2. 建议使用 **Chrome / Edge** 等现代浏览器。
3. 页面右上角显示版本号（如 `v1.0.0`），便于确认当前前端版本。

## 全局布局

### 左侧导航

| 菜单 | 路径 | 说明 |
|------|------|------|
| 概览 | `/dashboard` | 系统与任务总览 |
| 项目管理 | `/projects` | 项目 CRUD、归档 |
| 数据采集 | `/collect` | 上传、URL、远程推送 |
| 数据增强 | `/augmentation` | Albumentations 增强任务 |
| 数据标注 | `/annotation` | 目标检测 / 语义分割标注 |
| 模型训练 | `/training` | Ultralytics YOLO 训练 |
| 模型管理 | `/models` | 已训练模型列表、下载、导入 |
| 模型部署 | `/deployments` | 在线推理与 API |
| 模型验证 | `/validation` | 多模型对比测试 |
| 客户端 API | `/client-api` | Token、示例代码、联调 |

左下角可 **折叠 / 展开** 侧栏。

### 顶部「当前项目」

- 多数页面在顶部提供 **当前项目** 下拉框。
- **请先选择项目**：选择后，该页的数据集、模型等列表通常只显示当前项目下的资源。
- 未建项目时，先到 **项目管理** 创建。

### 右上角

- **授权状态**：点击可打开激活对话框，详见 [软件授权](/guide/license)。
- **版本号**：当前前端构建版本。

## 概览页

![概览](/screenshots/01-dashboard.png)

概览展示数据集数、图片数、增强任务数、训练任务数等统计；GPU 信息、磁盘容量（若后端返回）；**快速操作** 可跳转采集 / 增强 / 训练 / 项目；**最近训练任务** 可进入训练详情。
