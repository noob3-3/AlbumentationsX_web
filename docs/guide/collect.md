# 数据采集

![数据采集](/screenshots/06-collect.png)

**前提**：在顶部选择 **当前项目**。目标数据集列表只显示该项目下的数据集。

页内按标签切换采集方式：

## 本地文件上传

1. 选择目标数据集（可点 **新建数据集**）。
2. 将图片拖到上传区或点击选择。支持 JPG / PNG / BMP / WebP，单次最多 500 张。
3. 点击 **开始上传**。

## 语义掩膜 PNG

用于已设为「语义分割」的数据集。将单通道 PNG 掩膜上传，文件名需与对应原图 stem 一致（如 `photo.png` 对应 `photo.jpg`）。

- 仅 PNG；像素值 = 类别 id（`0 .. nc-1`），`255` = 忽略
- 需与对应原图同宽高
- 服务端写入 `semantic_masks/`

## 带标签上传

按页面说明上传 YOLO 格式（`images` + `labels` 等），图片与标签文件名需对应。适合已有标注成果批量导入。

## URL 批量采集

按提示填写图片 URL 列表，由服务端拉取并写入所选数据集。

## 客户端远程推送

现场设备或脚本可通过 HTTP 推送图片。需要 **X-Api-Token**，详见 [客户端 API](/guide/client-api)。
